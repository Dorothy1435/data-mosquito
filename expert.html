          데이터, 계산 방식, 검증, 알려진 한계를 그대로 공개합니다.

          v5 — 실측 모기 채집수로 학습한 모형 지금 화면 점수

          2026시즌 MOSCOM 장비 실측 694개 지점-일(178개 지점, 152일)로 직접 학습했습니다. 날씨·낮 길이 등 22개 특성을 쓰는 부스팅 트리가 시간 효과를, 발생원·인구·하천으로 학습한 공간 모형이 구역 수준을 맡고, 아래 v4 밀도위험을 20% 섞습니다. 모기지수 = 100 × log(1+예상 채집수) / log(1+1200).

          실측 일치 순위상관 0.22 → 0.70 일별 도시평균 0.49 → 0.91 처음 보는 지점·기간 0.65~0.68

          6~7월 정점 뒤 8~9월 줄어드는 실제 계절 흐름을 맞춥니다(v4는 기온만 봐서 8월을 정점으로 봤습니다). 예상 범위는 교차검증 잔차로 만든 50% 예측구간입니다.

          한계: 장비 자료가 한 시즌뿐이고 10월 이후 장비 자료가 없습니다. 트랩이 대부분 공원이라 "공원형 트랩 기준" 값입니다. 서버가 응답하지 않으면 아래 v4 수식 모델로 자동 전환됩니다.

          모델 검증 — 두 방향에서 실제와 대조 v4 수식 모델

          예측을 서로 다른 독립된 실측 두 가지와 비교했고, 둘 다 강하게 일치했습니다. 두 실측 모두 검증에만 쓰고 점수 계산에는 넣지 않습니다.

          공간 밀도위험 ↔ 실제 방역민원 +0.951 시간 예측 활동 ↔ 실측 유충 +0.996

          ① 공간 검증 — 어느 구역이 위험한가

          예측한 밀도위험을 실제 2025년 방역민원 밀도와 비교하니 순위 상관 +0.951. 개수 기반 이전 버전은 −0.258로 방향이 반대였는데 밀도로 바로잡았습니다.

          각 점은 구역 하나, 빨간 점은 회현동(모두 최상위). 우상향할수록 예측과 실제가 일치합니다. (민원 보유 13개 구역)

          ② 시간 검증 — 언제 위험한가

          모델의 날씨 활동곡선(Brière)이 실제 유충 발생과 맞는지 봤습니다. 유충 실측 1,086개 지점·2년(2024–2026)·5.4만 건을 월별로 모아 예측과 겹쳐보니 상관 +0.996으로 거의 포개집니다.

          두 선(모델 예측 · 실측 유충)을 0~1로 맞춰 겹쳤습니다. 7~8월 정점, 겨울 0 — 모델이 실제 계절 흐름을 그대로 재현합니다.

          모니터링 커버리지 — 어디를 더 채집해야 하나

          성충·유충 실측의 가중치를 높이려면, 채집이 특정 지역이 아니라 동네별로 촘촘해야 합니다. 현재 실측 채집 지점의 분포를 진단했습니다.

          -

          데이터

          김해시 방역현황보고 시스템(sodamap)에서 발생원 시설 16종(정화조·개인하수/오수처리·축산·저수지·타이어·폐기물·고물상·수경시설·공중화장실·공원 등) 약 1.5만 개소를 좌표로 읍·면·동에 배정하고, 행정동 경계 폴리곤으로 면적을, 주민등록·100m 격자로 인구를 확보했습니다. 2025년 방역민원 383건은 검증 전용으로만 썼습니다(점수 계산에 미포함).

          계산 방식

          발생원 시설(16종)을 곤충학적 가중치로 합산해 면적으로 나눈 '발생원 밀도'와 '인구 밀도'를 로그 정규화·평균해 밀도위험(0~1)을 만들고, 여기에 실시간 날씨 활동지수를 곱해 모기지수를 냅니다. 활동지수는 유효기온(당일 29% + 최근 7일 71%)을 Brière 곡선(30℃ 정점)으로 평가하고, 습도·최근 7일 강수·풍속으로 보정합니다. 유충 검출률은 민원과 음의 상관이라 위험 계산에서 빼고 '시설 관리상태' 참고지표로만 씁니다.

          알려진 한계 (투명 공개)

          • 성충 포집 이력 99.6%가 합성 샘플이라 구역별 밀도 학습에 쓰지 않았습니다. 기온 반응곡선의 '형태'를 잡는 데만 쓰고 실측 장비 427건으로 방향만 교차확인했습니다.
          • 유충 조사 이력도 구역별 검출률이 94~96%로 균일해 신호가 없어 미사용(관리상태 지표로만).
          • 정화조(청소대상)은 '청소 이력' 데이터라, 같은 정화조의 반복 청소를 고유 시설로 보정했습니다(총 6,000→4,123, 구역 순위·검증에는 영향 없음). 청소 직후 2~4주는 유충이 제거돼 일시적으로 위험이 낮아지지만, 이 시점 효과는 아직 실시간 반영하지 못합니다.
          • 민원 표본이 작습니다(383건·13개 구역). 진영·진례·한림·장유는 자료 미제공(결측)이라 추정치이며 신뢰도 '낮음'으로 표기됩니다. 민원 0건을 안전으로 읽으면 안 됩니다.
          • 민원은 사람이 신고하는 것이라 인구 많은 곳에 몰려 검증에 부분적 순환이 있습니다(발생원밀도 단독으로도 +0.692).
          • 화목동은 법정동이라 100m 격자로 인구를 추정했고, 기온 상한(40℃)은 실측이 아닌 문헌값입니다.

          주의할 점

          구역 단위가 17개로 작아 예측형보다 위험 스크리닝·방제 우선순위 모델로 활용하는 것이 적합합니다. 날씨는 구역 대표 좌표 기준이며, 결과는 참고용 예상값입니다.
