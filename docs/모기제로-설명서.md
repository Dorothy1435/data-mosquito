# 모기제로 서비스 설명서

작성일 2026-10-06 · 기준 버전 main 0ab7d93 + 10-06 작업분(미커밋) · 주소 https://mosquito-zero.vercel.app

## 1. 서비스 개요

모기제로는 김해시 발생원 자료와 실시간 날씨로 **오늘의 모기지수**를 예보하고, 시민이 외출 전에 "나가도 되는지, 무엇을 챙길지"를 한 화면에서 보게 하는 웹 서비스입니다. 앱 설치나 로그인 없이 휴대폰 브라우저에서 바로 쓰고, 홈 화면에 추가하면 앱처럼 열립니다.

| 항목 | 내용 |
|---|---|
| 대상 | 김해 시민(어르신 포함), 외국인 주민, 보건소 방역 담당자 |
| 화면 | 홈(오늘의 모기), 모기 도감, 전문가용(김해 모델), 사이트 소개, 개인정보 처리방침 |
| 핵심 수치 | 모기지수 0~100점, 5단계(매우 양호·양호·보통·위험·매우 위험) |
| 기술 | HTML·CSS·JavaScript 정적 사이트, Vercel 배포, 서버 함수 3개(AI 도우미·사진 판별·제보) |
| 외부 자료 | 김해시 방역현황보고 시스템(소다맵), Open-Meteo 날씨·대기질, OpenStreetMap 지도 |
| 모델 | 수식 기반 모델 v4 (학습 모델 아님). 2025년 방역민원 밀도와 순위상관 +0.951, 유충 월별 발생과 +0.996 |

모든 지수는 **참고용 예상값**이며 화면 곳곳에 그렇게 표시합니다.

## 2. 홈 화면 (index.html)

위에서 아래로 9개 묶음입니다.

### 2-1. 상단 바
- 로고와 "모기제로". 누르면 홈으로.
- 메뉴 6개: 오늘 하루 · 챙길 것 · 사진으로 알아보기 · 우리 동네 · 모기 도감(별도 화면) · 전문가용(검은 알약 버튼, 별도 화면). 모든 화면에서 같은 메뉴를 씁니다.
- **지역 선택**: 김해와 경남 17개 시·군(창원·진주·양산·거제·통영·사천·밀양·함안·창녕·거창·고성·하동·합천·남해·산청·함양·의령). 김해 밖은 날씨 기반 일반식으로만 계산하고 동네 순위·지도 원은 제공하지 않습니다.
- **현재 위치로**: 브라우저 GPS 1회. 날씨 조회에만 쓰고 저장하지 않으며, 날씨 서버에는 약 1km 단위로 반올림한 좌표만 보냅니다. 거부해도 지역 선택으로 쓸 수 있습니다.
- 휴대폰에서는 "메뉴" 버튼으로 접힙니다.

### 2-2. 첫 화면
- 짙은 남색 바탕 카드. 오른쪽에 김해 시 경계와 읍면동 경계(통계청 2013 행정경계)를 가는 선으로 그리고, 17개 동네를 오늘 모기지수 색·크기의 원으로 띄웁니다. 내 동네는 흰 테두리와 "내 동네" 이름표. 여름에 위험한 동네는 주황·빨강으로 바뀝니다. 지역을 창원·진주 등 경남 시·군으로 바꾸면 그 시·군 경계와 지금 보는 지점 한 점으로 바뀝니다(동네별 자료는 김해만). "경남 한눈에" 버튼을 누르면 경남 18개 시·군 경계 위에 시·군마다 오늘 점수 색 점이 뜨고, 김해는 "동네별 정밀"로 표시됩니다(그 밖은 날씨로 추정). 김해가 아닌 시·군을 고르면 이 보기가 기본입니다.
- 지금 상태 한 줄: 시각 · 기온 · 날씨 · "실제 날씨" 또는 "샘플" 표시.
- **오늘 모기지수** 큰 숫자. 0에서 굴러 올라옵니다. 기본 지역(김해)을 먼저 그린 뒤 현재 위치를 확인하므로 새로고침 직후 바로 보입니다.
- 단계 아이콘(5칸 막대, 찬 칸 수 = 단계)과 단계 이름. 색·글자·아이콘 세 가지로 단계를 구분합니다.
- 한 줄 결론 2줄: 단계별 문구("적은 편이에요.") + 행동 문구("가볍게 다녀오세요." / "기피제 하나면 충분해요." / "긴 옷과 기피제 챙기세요." / "오늘은 되도록 실내에서."). 앞으로 12시간 안에 크게 늘면 "저녁엔 긴 옷 하나."처럼 그 시각을 먼저 말합니다.
- **모기 잡기**: 모기 한 마리가 사진 위를 혼자 날아다니고 마우스를 피해 도망갑니다. 마우스는 모기약 통 모양이고, 누르면 약이 퍼집니다. 모기 가까이에서 누르면 빙글 돌며 떨어지고 "잡았다! n마리째"가 뜬 뒤 새 모기가 가장자리에서 날아옵니다. 휴대폰은 손가락으로 누릅니다. '움직임 줄이기' 설정이면 모기와 게임을 숨깁니다.
- 안내 줄: 참고용 고지, 위치 비저장 안내, 위도·경도, 날씨 갱신 시각, 지역 선택/GPS 여부, 신뢰도(높음·보통·낮음), 날씨 실패 시 "다시 불러오기" 버튼.

### 2-3. 오늘 한눈에 (카드 6칸)
사진 카드 아래에 걸쳐 올라오는 흰 카드입니다. 칸마다 이름 → 큰 숫자 → 설명 한 줄.

| 칸 | 큰 숫자 | 설명·그림 |
|---|---|---|
| 지금 모기지수 | 점수 | 단계 아이콘 + 단계 이름 |
| 가장 많은 때 | 시각(예: 낮 12시) | 24시간 작은 선 그래프, 최고점 표시, 점수 |
| 기온 | 현재 기온 | 체감 온도 |
| 비 올 확률 | % | 원형 게이지, "우산 챙기세요/괜찮아요" |
| 우리 동네 순위 | n번째 | 점 17개 중 우리 동네만 파랑 (김해만) |
| 챙길 것 | 개수 | 켜진 준비물 아이콘과 이름 |

숫자 굴림, 선 그리기, 게이지 차오름, 점 등장은 화면에 들어올 때 한 번만 재생됩니다.

### 2-4. 지금부터 24시간
- 막대 24개. 높이 = 모기지수. 지금은 검정, 가장 많은 때는 파랑, 나머지 회색. 세 시간마다 시각 표시.
- 흐름 한 줄: "저녁 7시부터 늘어나서 밤 9시에 가장 많아요 (63점 · 위험)" 또는 "하루 종일 크게 달라지지 않아요" 식으로 자동 작성.

### 2-5. 나가기 전에 챙길 것
켜짐/꺼짐 스위치 목록 5개. 날씨 값이 기준을 넘으면 켜집니다.

| 준비물 | 켜지는 기준 | 표시 이유 예 |
|---|---|---|
| 기피제 | 모기지수 41점 이상, 또는 12시간 안에 61점 이상 | "지금 42점" / "19시 63점" |
| 선크림 | 자외선 지수 3 이상(앞 8시간 중 최고) | "자외선 4" |
| 우산 | 비 오는 중, 또는 강수확률 40% 이상 | "비 63%" |
| 물 | 체감온도 28도 이상 | "체감 30도" |
| 마스크 | 초미세먼지 36 이상 또는 미세먼지 81 이상 | "초미세먼지 17" |

- 한 줄 요약: "나들이 좋음. 선크림 그리고 우산 챙기세요."
- 행동요령 3개(①②③): 김해는 정밀 모델의 시민 요령, 그 밖은 단계별 일반 요령.
- 꽃가루는 기상청 인증키가 없어 아직 반영하지 않습니다.

### 2-6. 사진으로 모기 알아보기
- **카메라로 찍기**: 페이지 안에서 뒷면 카메라가 바로 열립니다. 동그라미 안내선, 셔터 버튼, 찍으면 흰 번쩍임 후 판별로 넘어갑니다. 권한 거부나 미지원 기기는 휴대폰 기본 카메라로 넘어갑니다.
- **앨범에서 고르기**: 저장된 사진 선택.
- 처리: 휴대폰에서 긴 변 1024px로 줄이며 촬영 위치 등 사진 속 정보(EXIF)를 지운 뒤 서버로 보냅니다. 서버는 저장하지 않고 학습하지 않습니다.
- 결과: 흰줄숲모기 · 얼룩날개모기 · 집모기류 · 모기 아님 · 알 수 없음 중 하나. 확신도 3단계("거의 확실해요 / 그럴 가능성이 높아요 / 확실하지 않아요"), AI가 본 특징, 다시 찍을 때 팁, 종류별 설명·옮기는 병·할 일. 빨간집모기와 작은빨간집모기는 사진으로 구분이 어려워 "집모기류"로 묶습니다.
- 어디서든 쓰도록 왼쪽 아래 "모기 찍기" 떠 있는 버튼이 첫 화면을 지나면 나타납니다.
- 잘 찍는 법 3가지 안내(크게, 밝게, 날개와 다리가 보이게).
- 현재 상태: 사이트에 연결된 AI 키(Groq)에 사진을 읽는 모델이 없어 "판별하지 못했어요"가 나옵니다. OpenAI 또는 Gemini 키를 넣으면 동작합니다.

### 2-7. 오늘 하루 (검정 판)
- **시간대별 모기지수**: 지금부터 두 시간 간격 막대 12개(지금 흰색, 가장 많은 때 파랑). 아래에 "가장 많은 때 / 가장 적은 때" 시각·점수·설명.
- **나들이 지수** 0~100점, 4등급(나쁨·보통·좋음·매우 좋음). 기온 26% · 비 24% · 모기 30% · 자외선 12% · 바람 8%의 가중 평균에, 비 오는 중 28점 이하, 자외선 매우 강함 58점 이하 같은 상한을 둡니다. 추천 시간대(낮 시간 중 가장 좋은 구간), 한 줄 조언, 4단계 눈금, 조건 5줄(기온·비·자외선·바람·모기).
  - 알려진 문제: 모기가 보통이어도 날씨가 좋으면 "매우 좋음"이 나옵니다. 모기 단계별 상한을 추가할 예정입니다.
- **오늘 가기 좋은 공원** 3곳: 김해 도시공원 245곳 중 "나들이 지수 − 그 공원의 모기 위험(동네 밀도위험 + 공원 유형 보정) + 거리·넓이·시설 가산점"으로 고릅니다. 수변공원은 물가라 감점, 어린이·소공원은 가산. 카드에 순위·동네·이름·이유를 보여 주고 누르면 OpenStreetMap에서 위치가 열립니다. 자유 이용 사진이 있는 5곳(연지·왕릉·봉황대·해반·율하천공원)은 사진, 나머지는 위치 지도 조각. 공원별 모기 실측값은 없다고 함께 표시합니다.
- **앞으로 5일**: 요일 · 날짜 · 일 최고 모기지수 · 단계(아이콘). 실제 날씨가 있을 때만.

### 2-8. 우리 동네
- **지도**(Leaflet + OpenStreetMap): 김해 17개 읍·면·동 원 마커. 색 = 단계, 누르면 지역명·모기지수·단계·날씨 요약. 현재 위치 마커, 선택 지점 마커. 범례 5단계.
- **발생원 히트맵 보기**: 16종 발생원(정화조·개인하수처리·축산·저수지·폐타이어·수경시설·공중화장실·도시공원 등) 밀도를 동네별 원 크기·색으로 표시. 범례 낮음~매우 높음, 설명 문구.
- **우리 동네는 김해에서 n번째**: 17곳 중 순위. "동네별 오늘 모기지수" 목록(상위 5곳과 내 동네, "17곳 모두 보기"로 펼침). 동네를 누르면 그 동네의 점수·예상 범위·주요 발생원·오늘 요령과 전문가 화면 링크가 든 카드가 펼쳐짐. 김해 밖이면 "김해 지역만 순위 제공" 안내.

### 2-9. 왜 이 점수일까 (회색 판)
- 날씨 5칸: 기온 · 습도 · 오늘 강수량 · 풍속 · 날씨 상태, 각각 모기와의 관계 한 줄.
- 이유 목록: 지역과 점수·단계, 김해 정밀 모델 적용 내용(주요 발생원, 구역 유형, 발생원 개수/면적), 예상 범위와 발생원 위험 순위. 김해 밖은 "날씨만으로 추정" 고지.
- "계산 근거 자세히 보기": 날씨 상세(체감·일출·일몰 등), 추가 분석, 계산식 행별 값.
- 출처 문구(Open-Meteo 시간별 예보 + 김해 정밀 모델).

### 2-10. 우리 주변 모기 4종 · 오늘의 한 마디 · 제보
- 모기 4종 사진 카드(빨간집·작은빨간집·흰줄숲·얼룩날개): 이름, 특징, 옮기는 병, 막는 법. 유충 사진과 "물을 비우면 끊을 수 있어요". 도감 전체 보기 링크.
- **오늘의 한 마디**: 14개 상식 문구가 날짜별로 돌고, 비·더위·밤·모기 많음/적음 상황이면 그에 맞는 문구가 먼저 나옵니다.
- **여기 모기 있어요** (시험판): 제보 3종 — 모기 봤어요 · 물렸어요 · 고인 물 발견. 위치 이용 안내(무엇·왜·보관)에 동의하면 GPS 1회로 지도에 표시, 거부하면 동네 직접 선택. 김해 밖은 차단. 지금은 저장 스위치가 꺼져 있어 서버에 보내지 않고 화면을 닫으면 사라집니다. 켜면 100m 단위 반올림·동 이름·종류만 저장하고 누가 보냈는지는 저장하지 않으며, 공개는 동 단위 개수만, 보건소가 확실·아마도·모르겠음·반려로 확인합니다.
- 바닥글: 참고용 고지, 날씨·지도·발생원·사진 출처와 라이선스 링크, 도감·전문가용·소개·개인정보 처리방침 링크.

### 2-11. AI 도우미 (모든 화면 오른쪽 아래)
- 사이트 안의 사실(모기지수 정의·계산·검증·발생원 16종·예방 요령·매개모기 4종)과 오늘 구역별 점수, 공원 자료로만 답합니다. 숫자는 AI가 만들지 않고 화면이 계산한 값만 씁니다.
- 모기와 무관한 질문은 정중히 거절, 사이트 정보로 답할 수 없으면 그렇게 말합니다. 산책·나들이 질문은 모기 위험 질문으로 받아 답합니다.
- 후속 질문 3개 제안, 최근 8개 대화 기억, 질문 500자 제한, "개인정보는 적지 마세요" 안내.
- 제공자: Groq(무료) → OpenAI → Gemini 순으로 자동 전환. 쓸 수 있는 모델을 매번 확인해 은퇴한 모델 때문에 멈추지 않습니다.

## 3. 모기 도감 (mosquito-info.html)
- 첫 화면: **사진으로 모기 알아보기**(홈과 같은 기능: 카메라로 찍기·앨범에서 고르기·AI 판별 결과). 그 아래 "모기를 알면 물을 비우게 돼요" + 로고.
- 숫자로 보는 국내 모기: 감염병 매개 가능 14종, 얼룩날개모기 52%(2013–2015), 알에서 어른까지 7–10일. 출처 이동규, 대한의사협회지 2017.
- 4종 상세(사진·학명·특징·옮기는 병·사는 곳·막는 법): 빨간집모기(웨스트나일열, 정화조·하수구), 작은빨간집모기(일본뇌염, 논·축사), 흰줄숲모기(뎅기·지카·치쿤구니야, 폐타이어·용기), 얼룩날개모기(말라리아, 논·늪).
- 한살이 4단계(알·유충·번데기·어른), 세 단계가 물속. 유충 사진과 물 비우기 안내.
- 집 주변 확인 6가지(화분 받침, 옥상·에어컨 배수구, 웅덩이, 방충망, 긴 옷·기피제, 주말 점검), 감염병 주의(예방접종·해외여행 후 증상), 사진 출처.

## 7. 모기지수 계산 방식
**2026-10-06부터 v5(실측 학습 모형)가 점수를 냅니다.** 저장소 주인이 만든 파이썬 모델을 Vercel 서버 함수(/api/model)로 돌리고, 홈·전문가 화면이 그 결과를 받아 씁니다. 2026시즌 장비 실측 채집수 694건(178지점·152일)으로 학습했고, 날씨·낮 길이로 시간 효과를, 발생원·인구·하천으로 구역 수준을 계산합니다. 실측과의 순위 일치 0.70(일별 도시평균 0.91). 모기지수 = 100 × log(1+예상 채집수) / log(1+1200). 서버가 응답하지 않으면 v4 수식 모델로 자동 전환되고, 시간별·일별 흐름(모양)은 v4 것을 v5 수준에 맞춰 씁니다.

(아래는 예비로 남겨 둔 v4 수식 모델)
- 모기지수 = 100 × 날씨활동지수 × (0.30 + 0.70 × 밀도위험)
- 밀도위험(0~1): 발생원 밀도(개/㎢)와 인구 밀도(명/㎢)를 로그 정규화해 평균. 개수가 아니라 단위면적당 밀도.
- 날씨활동지수: 유효기온(당일 29% + 최근 7일 71%)을 30℃ 정점 곡선으로 평가하고 습도·최근 강수·풍속으로 보정.
- 5단계: 0~20 매우 양호 · 21~40 양호 · 41~60 보통 · 61~80 위험 · 81~100 매우 위험.
- 김해 밖: 기온·습도·강수·풍속·시간대·계절·지역 밀도 가중치의 일반식.
- 검증: 2025년 방역민원 밀도와 순위상관 +0.951, 유충 월별 발생과 +0.996. 민원·유충은 점수 계산에 넣지 않아 순환이 없습니다.
- 단계 판정은 반올림한 정수 기준이며, 홈·전문가 화면·챗봇·파이썬 이식본(mosquito_model_portable.py)이 같은 5단계를 씁니다.
- 한계: 17구역 단위라 정밀 예측보다 위험 선별용. 수식 모델이며 학습 모델이 아님. 가을철 실내 모기 체감은 반영되지 않음.

## 9. 앱·기술 특징
- **앱 설치(PWA)**: 홈 화면에 추가하면 주소창 없이 앱처럼 열리고, 인터넷이 잠깐 끊겨도 마지막 화면이 뜹니다. 날씨·AI·제보는 저장하지 않아 오래된 값을 보여 주지 않습니다.
- **공유 미리보기**: 카카오톡·SNS에 링크를 보내면 제목·설명·그림이 뜹니다.
- **반응형**: 360px 휴대폰까지 가로 넘침 없음, 글자 14px 이상, 누르는 영역 44px 이상.
- **접근성**: 키보드 조작, 화면 읽기용 숨은 설명, 색·글자·아이콘 3중 단계 표시, '움직임 줄이기' 설정 존중.
- **움직임**: 숫자 굴림, 제목 줄별 등장, 막대 자라남, 스크롤 등장, 모기 잡기(모기약 커서), 카드 순차 등장.
- **서버 함수**: `/api/ask`(AI 도우미), `/api/identify`(사진 판별), `/api/report`(제보 저장, 스위치 꺼짐). API 키는 서버 환경변수에만 있고 브라우저로 나가지 않습니다.
- **디자인**: 토스(toss.im)의 실측 글자 체계(굵기 700, 48·32·24px, 자간 −2%)와 회색 단계, 애플식 명암 판 교차, 보건소 로고 색.

## 10. 현재 제한과 남은 일
- 사진 판별: AI 키(OpenAI/Gemini) 추가 전까지 동작 안 함.
- 제보: 저장 스위치 꺼짐. 저장하려면 위치정보법 절차(위치기반서비스사업 신고·개인위치정보 약관) 필요.
- 개인정보 처리방침 빈칸, 소다맵 자료 공개 승인, Vercel 요금제 확인(무료는 월 100GB).
- 트래픽 대비: 날씨 서버 캐시, 지도 타일 교체, AI 호출 한도, 배경 사진 압축 예정.
- 나들이 지수 모기 상한, 가을 실내 모기 안내, 검색 등록 파일(robots·sitemap) 예정.
- 미구현: 꽃가루, 숏폼, 사진 기증, 보건소 확인 화면, 데이터 개방, 다국어, 스토어 앱.
