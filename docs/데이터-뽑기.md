# 모기제로 데이터 뽑기

Supabase 대시보드 → SQL Editor 에서 아래 한 줄을 실행하고, 결과 오른쪽 위 **Export → CSV** 를 누르면 엑셀로 받을 수 있다.
`report` 묶음의 보기는 사이트·앱에서는 읽을 수 없고 대시보드에서만 읽힌다(만드는 SQL: `supabase/report-schema.sql`).

| 알고 싶은 것 | 실행할 SQL |
| --- | --- |
| 회원 전체 한 줄 요약 (닉네임·이름·휴대폰·이메일·잡은 모기·뛰어런 km·사진) | `select * from report."회원";` |
| 모기 잡기 상위 10명 + 연락처 (상품 지급) | `select * from report."상품_모기잡기";` |
| 뛰어런 상위 10명 + 연락처 (상품 지급) | `select * from report."상품_뛰어런";` |
| 날짜별 가입·잡은 모기·뛰어런·사진 기증 | `select * from report."일별활동";` |
| 사진 기증 목록 (검토 상태·확인한 종) | `select * from report."사진기증";` |
| 회원별 동의 현황 (최신) | `select * from report."동의";` |
| 회원 수 | `select count(*) from public.profiles;` |
| 최고 관리자·직원 목록 | `select nickname, role, is_admin from public.profiles where role = 'staff' or is_admin;` |

## 원본 표 (필요할 때만)

| 표 | 내용 |
| --- | --- |
| `profiles` | 회원 (닉네임, 권한, 가입 시각) |
| `member_contacts` | 이름·휴대폰 (본인만 열람, 한 번 저장하면 본인은 못 바꿈) |
| `game_runs` | 모기 잡기 한 판(도전) 또는 한 묶음(그냥 잡기, stage 0) |
| `game_scores` | 시즌별 누적 잡은 수 (랭킹 기준) |
| `run_sessions` | 뛰어런 한 번 (거리·시간·걸음, 달린 길 좌표는 없음) |
| `photo_donations` | 기증 사진 (파일은 Storage `photo-donations`) |
| `user_data` | 기기 기록 보관 (game: 골드·무기, runs: 뛰어런 목록, photo: 판별 횟수) |
| `consents` | 동의 기록 (언제 무엇에 동의했는지) |

## 주의

- 이름·휴대폰이 들어간 파일은 개인정보다. 상품 지급이 끝나면 지우고, 메일·메신저로 돌리지 않는다.
- 이름·휴대폰을 고쳐야 할 때(본인 요청):
  `update public.member_contacts set real_name = '새이름', phone = '01012345678' where user_id = (select id from public.profiles where nickname = '닉네임');`
