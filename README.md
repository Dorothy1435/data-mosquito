# 모기제로

모기제로는 날씨와 지역 샘플 데이터를 바탕으로 오늘의 모기지수를 보여주는 웹앱입니다.

## 실행 방법

1. `index.html`을 브라우저에서 엽니다.
2. 로컬 JSON 파일을 읽기 위해 VS Code의 Live Server 같은 정적 서버를 사용하면 더 안정적입니다.

## 실제 날씨와 GPS

- 현재 위치 버튼을 누르면 브라우저 GPS로 현재 위치를 가져옵니다.
- 날씨는 Open-Meteo 공개 API를 사용합니다.
- API 요청이 실패하면 샘플 데이터로 자동 전환합니다.

## Vercel 배포 방법

1. Vercel에 로그인합니다.
2. 이 폴더를 Git 저장소에 연결하거나 Vercel CLI로 배포합니다.
3. 루트 디렉터리를 그대로 사용하면 됩니다.
4. 이 프로젝트는 빌드 단계가 없는 정적 사이트라서 별도의 build command가 필요하지 않습니다.

CLI를 사용할 경우 예시는 다음과 같습니다.

```bash
vercel
```

## 포함된 기능

- 기본 화면
- 지역 선택
- 현재 위치 기반 지역 이동
- 모기지수 계산과 단계 표시
- Leaflet 지도와 지역별 마커
- 샘플 날씨 및 지역 데이터 표시
- 사이트 소개 페이지와 모기 정보 페이지 분리
- 실제 날씨와 GPS 위치 연결
- 시간대별 모기지수 예보 차트 (Chart.js, 앞으로 24시간)
- 오늘 하루 중 가장 위험한 시간대와 안전한 시간대 안내
- 김해시 모기 위험 모델 페이지(`gimhae.html`): 행정 데이터(발생원 시설·방역민원)와 실시간 날씨를 결합해 읍·면·동별 모기지수·발생원 분석·방제 우선순위 제공
- 함께 보는 나들이 지수(`index.html`): 식중독지수 · 미세먼지 · 초미세먼지를 모기지수 옆에 함께 표시
- 오늘의 나들이 추천(`gimhae.html`): 구역에서 가장 쾌적한 공원 1곳 + 김해 관광지·박물관·도서관 중 가장 쾌적한 1곳 안내
- 시민용 / 전문가용 보기 전환(`gimhae.html`): 방제 약품·발생원 통계 등 방역 담당자용 화면을 시민 보기에서 접어 둠
- 모기 정보 페이지 시각 자료: 국내 매개모기 4종 실제 사진, 유충 사진, 발생원·활동시간대 일러스트

## 김해시 모델 안내

`mosquito_model_portable.py`(원본 Python 모델)를 브라우저용 `mosquito-model.js`로 그대로 포팅했습니다. 두 구현의 출력이 동일함을 119개 케이스로 검증했습니다. 페이지(`gimhae.html`)는 김해시 대표 지점의 실시간 날씨를 입력값으로 사용하며, 실패 시 모델에 내장된 월별 평년값으로 자동 대체합니다.

## 데이터 안내

실제 모기 관측 API는 아직 연결하지 않았고, 현재는 `data/mosquito-sample.json`과 `data/regions.json`의 샘플 데이터를 사용합니다.

### 나들이 지수의 데이터 출처 (연동 여부)

| 지수 | 연동 여부 | 출처 · 사유 |
| --- | --- | --- |
| 미세먼지(PM10)·초미세먼지(PM2.5) | **실측 연동** | Open-Meteo 대기질 공개 API(인증키 불필요). 등급은 환경부 대기환경기준 4단계를 적용 |
| 식중독지수 | **연동하지 않음 (자체 산출)** | 식약처 식중독예측지도 공공 API는 **인증키 발급이 필요**해 이 저장소에서 바로 연동할 수 없습니다. 대신 오늘 기온·습도로 **자체 산출**한 참고값을 쓰고, 화면에 `자체 산출` 배지와 안내 문구로 명시합니다. 단계 이름(관심·주의·경고·위험)만 식약처의 공개 기준을 따랐습니다. 식약처 값을 그대로 가져온 것처럼 표시하지 않습니다 |

인증키를 발급받아 실제 식약처 값으로 바꾸려면 `script.js`의 `computeFoodPoisoningIndex()`를 API 호출로 교체하고, 타일의 배지를 `자체 산출` → `실측`으로 바꾸면 됩니다.

### 관광지 좌표

`data/gimhae-attractions.json`의 위경도는 **OpenStreetMap(Nominatim) 공개 지오코딩 결과**입니다. 임의로 추정한 좌표가 아닙니다. 각 장소가 속한 읍·면·동은 모델의 `nearestDistrict()`로 실행 시점에 배정합니다.

### 모기 사진 · 일러스트

- `assets/mosquito/` — 국내 매개모기 4종과 유충의 실제 사진. 출처와 라이선스는 `assets/mosquito/credits.json`과 모기 정보 페이지 하단에 표기했습니다. 흰줄숲모기·얼룩날개모기·유충은 미국 질병통제예방센터(CDC, James Gathany) 퍼블릭 도메인, 작은빨간집모기·빨간집모기는 위키미디어 커먼즈 CC BY-SA 4.0입니다.
- `assets/illustrations/` — 직접 제작한 SVG 일러스트(발생원 4종, 하루 활동 시간대 그래프, 계산 흐름도).

## API 키 안내

날씨 API를 붙일 때는 `config.example.js`를 복사해 `config.js`를 만들고 키를 넣으세요.

`config.js`에는 실제 키가 들어가므로 Git 저장소에 포함하지 않아야 합니다.

## AI 도우미(선택) 설정 — `api/ask.js`

화면 우측 아래 "🦟 모기 도우미"는 사이트 정보로만 답하는 AI 챗봇입니다. 무료로 동작하며, 설정하지 않으면 안내 메시지만 표시됩니다(사이트는 정상 작동).

1. [Google AI Studio](https://aistudio.google.com/apikey)에서 무료 Gemini API 키를 발급받습니다(카드 등록 불필요).
2. Vercel 프로젝트 → **Settings → Environment Variables**에 다음을 추가합니다.
   - Name: `GEMINI_API_KEY`, Value: 발급받은 키
3. 다시 배포(Redeploy)하면 도우미가 켜집니다.

- 키는 서버리스 함수(`api/ask.js`)에서만 읽혀 **브라우저에 노출되지 않습니다.**
- 구역 점수 등 숫자는 브라우저가 모델로 계산해 함께 보내므로 **AI가 수치를 지어내지 않습니다(환각 방지)**. 사이트 범위를 벗어난 질문은 정중히 거절합니다.
- 무료 티어에는 하루 요청 한도가 있습니다. 한도를 넘으면 잠시 후 다시 안내 메시지가 나올 수 있습니다.
