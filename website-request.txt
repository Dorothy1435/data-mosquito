# 모기 데이터 기반 생활환경 정보 웹앱 개발 요구사항

## 1. 프로젝트명

모기제로
Mosquito Zero

---

## 2. 프로젝트 개요

날씨 데이터와 지역별 모기 관련 데이터를 활용하여 사용자가 현재 위치 또는 선택한 지역의 모기 발생 위험도를 쉽게 확인할 수 있는 웹앱을 개발한다.

사용자는 미세먼지 지수를 확인하는 것처럼 오늘의 모기 지수를 확인할 수 있어야 한다.

오늘의 기온, 습도, 강수량, 풍속 등의 날씨 정보를 활용하여 모기 활동 가능성을 계산하고, 결과를 백분율과 단계로 표시한다.

또한 지도에서 지역별 모기 위험 지역을 확인하고, 모기의 특징, 주요 서식지, 모기 예방 방법 및 퇴치 방법 등의 생활정보도 제공한다.

---

## 3. 개발 목적

* 사용자가 오늘 모기가 많이 발생할 가능성을 쉽게 확인할 수 있도록 한다.
* 날씨와 지역 데이터를 이용하여 모기 위험도를 직관적으로 제공한다.
* 지도에서 모기 발생 가능성이 높은 지역을 확인할 수 있도록 한다.
* 사용자가 외출이나 야외활동 전에 모기 위험에 대비할 수 있도록 한다.
* 모기 서식지와 예방 방법 등 실생활에 필요한 정보를 제공한다.

---

## 4. 사용 기술

* HTML5
* CSS3
* JavaScript ES6 이상
* 외부 프레임워크 없이 기본 HTML, CSS, JavaScript를 중심으로 개발
* 지도 기능은 Leaflet.js 또는 Kakao Map API 사용
* 지도 기능을 빠르게 구현할 수 있도록 우선 Leaflet.js와 OpenStreetMap 사용
* 날씨 데이터는 OpenWeatherMap API 또는 기상청 단기예보 API 사용
* 데이터 시각화가 필요한 경우 Chart.js 사용 가능
* 아이콘은 Font Awesome 또는 SVG 아이콘 사용 가능

---

## 5. 기본 개발 원칙

* 데스크톱, 태블릿, 모바일에서 모두 사용할 수 있는 반응형 웹사이트로 제작한다.
* 모든 화면과 설명은 한국어로 작성한다.
* 처음 사용하는 사람도 기능을 쉽게 이해할 수 있도록 만든다.
* 전체 디자인은 깔끔하고 현대적인 환경정보 앱 스타일로 제작한다.
* 미세먼지 정보 앱이나 날씨 앱처럼 정보를 한눈에 파악할 수 있도록 구성한다.
* 과도하게 복잡한 애니메이션은 사용하지 않는다.
* 버튼, 메뉴, 지도 마커에는 마우스 오버 효과를 적용한다.
* API 연결에 실패해도 페이지 전체가 멈추지 않도록 예외처리를 한다.
* API 데이터가 없을 때는 샘플 데이터를 표시하고 샘플 데이터라는 안내문을 보여준다.
* 사용자에게 실제 데이터와 예측 데이터가 혼동되지 않도록 데이터 기준을 명확히 표시한다.

## 6. 프로젝트 폴더 구성

다음 구조를 기준으로 파일을 생성한다.

mosquito-app/
├── index.html
├── style.css
├── script.js
├── config.example.js
├── README.md
├── CLAUDE.md
├── website-request.txt
├── assets/
│   ├── images/
│   └── icons/
└── data/
├── mosquito-sample.json
└── regions.json

각 파일의 역할은 다음과 같다.

* index.html: 웹사이트 전체 화면 구조
* style.css: 디자인과 반응형 스타일
* script.js: 날씨 API, 지도, 모기지수 계산 및 화면 동작
* config.example.js: API 키 입력 예시
* README.md: 설치 방법, 실행 방법, API 키 설정 방법
* mosquito-sample.json: API 연결 실패 시 사용할 지역별 모기 샘플 데이터
* regions.json: 지역 이름과 위도·경도 데이터

실제 API 키가 들어가는 config.js는 Git 저장소에 올라가지 않도록 안내한다.

## 7. 주요 사용자 흐름

### 사용자 접속

1. 사용자가 웹사이트에 접속한다.
2. 브라우저 위치정보 사용 여부를 요청한다.
3. 위치정보를 허용하면 현재 위치의 위도와 경도를 가져온다.
4. 현재 위치를 기준으로 날씨 데이터를 불러온다.
5. 날씨 데이터와 모기 관련 데이터를 이용하여 오늘의 모기지수를 계산한다.
6. 계산된 결과를 메인 화면과 지도에 표시한다.

### 위치정보를 허용하지 않은 경우

* 기본 지역을 서울로 설정한다.
* 사용자가 지역 검색창에서 직접 지역을 검색할 수 있도록 한다.
* 지역 선택 드롭다운 또는 검색 기능을 제공한다.

# 10. 메인 모기지수 영역

가장 중요한 정보이므로 페이지 상단에 크게 표시한다.

## 표시 정보

* 현재 지역명
* 현재 날짜
* 현재 시간
* 오늘의 모기지수
* 모기지수 백분율
* 위험 단계
* 간단한 행동 안내
* 마지막 데이터 갱신 시간

## 표시 예시

오늘의 모기지수

72%

위험

오늘은 모기의 활동 가능성이 높습니다.
저녁 외출 시 긴 옷과 모기 기피제를 준비하세요.

## 모기지수 시각화

원형 게이지 또는 반원형 게이지로 표시한다.

게이지 안쪽에 모기지수 백분율을 크게 표시한다.

예시:

* 18% 매우 양호
* 37% 양호
* 54% 보통
* 72% 위험
* 91% 매우 위험

단계별로 색상, 아이콘, 설명문이 변경되도록 한다.

# 11. 모기지수 단계 기준

모기지수는 0점에서 100점 사이로 계산한다.

## 단계 구분

### 0~20점: 매우 양호

* 색상: 파란색
* 모기 활동 가능성이 매우 낮음
* 일반적인 야외활동 가능

### 21~40점: 양호

* 색상: 초록색
* 모기 활동 가능성이 낮음
* 늦은 저녁에는 가벼운 주의 필요

### 41~60점: 보통

* 색상: 노란색
* 일부 지역에서 모기 활동 가능
* 공원이나 물가 방문 시 모기 기피제 권장

### 61~80점: 위험

* 색상: 주황색
* 모기 활동 가능성이 높음
* 야외활동 시 긴소매와 모기 기피제 사용 권장

### 81~100점: 매우 위험

* 색상: 빨간색
* 모기 활동 가능성이 매우 높음
* 야간 야외활동 최소화 권장
* 창문 방충망과 주변 고인 물 점검 필요

단계 기준은 별도의 JavaScript 객체로 관리하여 나중에 쉽게 수정할 수 있도록 한다.

# 12. 모기지수 계산 방식

실제 모기 관측 데이터가 제공되면 해당 데이터를 우선 사용한다.

실제 모기 관측 데이터가 없는 경우 날씨 데이터를 이용하여 예상 모기지수를 계산한다.

## 계산에 사용할 요소

* 현재 기온
* 최저기온
* 최고기온
* 습도
* 최근 강수 여부
* 최근 강수량
* 풍속
* 시간대
* 계절
* 실제 모기 관측 데이터
* 지역별 위험 가중치

## 기본 계산 예시

다음과 같은 구조로 계산한다.

mosquitoIndex =
temperatureScore × 0.30

* humidityScore × 0.25
* rainScore × 0.20
* windScore × 0.10
* seasonScore × 0.10
* regionalScore × 0.05

최종 결과는 0에서 100 사이로 제한한다.

## 기온 점수 예시

* 10도 미만: 매우 낮은 점수
* 10~15도: 낮은 점수
* 16~20도: 보통 점수
* 21~28도: 높은 점수
* 29~32도: 다소 높은 점수
* 33도 이상: 활동 감소를 고려하여 점수 조절

## 습도 점수 예시

* 습도 40% 미만: 낮음
* 습도 40~60%: 보통
* 습도 60~80%: 높음
* 습도 80% 이상: 매우 높음

## 강수 점수

최근 비가 왔거나 강수량이 일정 수준 이상이면 고인 물 발생 가능성을 고려하여 점수를 높인다.

단, 폭우가 내리는 현재 시점에는 모기 활동이 일시적으로 감소할 수 있으므로 현재 강수와 최근 강수를 구분한다.

## 풍속 점수

* 바람이 약하면 모기 활동 점수를 높인다.
* 바람이 강하면 모기 활동 점수를 낮춘다.

## 시간대 점수

* 새벽과 저녁 시간대에는 점수를 높인다.
* 한낮에는 점수를 낮춘다.
* 모기 종류마다 활동 시간대가 다를 수 있다는 안내를 표시한다.

## 중요 안내

이 계산식은 초기 서비스용 예상 모델이다.

공식적인 모기 예보나 질병 위험 진단으로 표현하지 않는다.

화면에 다음 문구를 표시한다.

“본 모기지수는 날씨와 지역 데이터를 기반으로 계산한 참고용 예상값입니다. 실제 모기 발생량과 차이가 있을 수 있습니다.”

# 13. 날씨 정보 영역

모기지수 계산에 사용된 날씨 정보를 카드 형태로 보여준다.

## 표시 정보

* 현재 기온
* 최고기온
* 최저기온
* 습도
* 강수량
* 강수 확률
* 풍속
* 날씨 상태

각 날씨 요소 아래에 모기 발생과 어떤 관련이 있는지 짧게 표시한다.

## 예시

습도 78%

습도가 높아 모기가 활동하기 좋은 환경입니다.

풍속 1.2m/s

바람이 약해 모기 활동 가능성이 높습니다.

최근 강수량 12mm

고인 물이 생겼을 가능성이 있어 주의가 필요합니다.

# 14. 모기지수 분석 근거 영역

사용자가 모기지수가 왜 높거나 낮은지 이해할 수 있도록 분석 결과를 제공한다.

## 예시

오늘 모기지수가 높은 이유

* 현재 습도가 78%로 높습니다.
* 최근 24시간 동안 비가 내렸습니다.
* 현재 풍속이 약합니다.
* 모기 활동이 활발한 저녁 시간대입니다.

오늘 모기지수를 낮추는 요소

* 현재 기온이 모기 최적 활동 범위보다 낮습니다.
* 낮 시간대라 모기 활동이 비교적 적습니다.

분석 이유는 날씨 값에 따라 자동으로 생성한다.

# 17. 모기 위험 지도

Leaflet.js와 OpenStreetMap을 사용하여 대한민국 지도를 표시한다.

## 기본 지도 기능

* 지도 확대 및 축소
* 현재 위치 표시
* 지역 검색
* 마커 클릭
* 위험도 범례
* 내 위치로 이동
* 전체 화면 보기
* 지도 데이터 새로고침

## 지도 시각화 방법

지역별 모기지수에 따라 지도 위에 색상을 표시한다.

* 매우 양호: 파란색
* 양호: 초록색
* 보통: 노란색
* 위험: 주황색
* 매우 위험: 빨간색

다음 방식 중 데이터에 적합한 방식을 선택한다.

* 원형 마커
* 히트맵
* 행정구역 색상 지도
* 클러스터 마커

초기 버전에서는 구현이 쉬운 원형 마커를 사용한다.

## 지도 마커 클릭 정보

마커를 클릭하면 팝업을 표시한다.

팝업 내용:

* 지역명

# 18. SODAMAP 데이터 연동 조사

다음 주소에 모기 또는 지역 관련 데이터가 있는 것으로 알려져 있다.

https://sodamap.co.kr:8448

Claude Code는 먼저 해당 서비스의 데이터 사용 가능 여부를 조사한다.

## 조사할 사항

* 공개 API가 제공되는지 확인
* API 문서가 있는지 확인
* 브라우저 개발자 도구의 Network 탭에서 데이터 요청 주소 확인
* Fetch 또는 XHR 요청 확인
* JSON, GeoJSON, CSV 형식 여부 확인
* 요청 파라미터 확인
* 응답 데이터 필드 확인
* 인증키 또는 토큰 필요 여부 확인
* CORS 허용 여부 확인
* 데이터 이용약관 확인
* 데이터 출처 표기 조건 확인
* 상업적 이용 가능 여부 확인
* 실시간 데이터인지 정적 데이터인지 확인
* 데이터 갱신 주기 확인

## 연동 가능한 경우

별도의 JavaScript 함수로 데이터를 불러온다.

예시 함수명:

* fetchSodamapData()
* normalizeSodamapData()
* displaySodamapMarkers()
* handleSodamapError()

원본 데이터 형식이 달라도 앱 내부에서는 다음 공통 형식으로 변환한다.

{
"id": "region-001",
"regionName": "서울특별시 종로구",
"latitude": 37.5729,
"longitude": 126.9794,
"mosquitoIndex": 72,
"riskLevel": "위험",
"observedAt": "2026-06-12T18:00:00",
"dataType": "observed",
"source": "SODAMAP"
}

## 직접 연동이 불가능한 경우

다음 가능성을 확인한다.

* 공개 API가 없음
* 로그인 또는 인증 필요
* 브라우저에서 CORS 오류 발생
* 서버 측 프록시가 필요함
* 이용약관상 자동수집이 제한됨
* 데이터 주소가 비공개임

직접 연동이 어렵다면 임의로 보안 제한을 우회하지 않는다.

HTML, CSS, JavaScript만으로 해결할 수 없는 경우 README.md에 이유를 설명한다.

다음과 같은 안내를 남긴다.

“현재 SODAMAP 데이터는 공개 API 또는 CORS 설정을 확인할 수 없어 브라우저에서 직접 연동하지 않았습니다. 정식 API 주소와 이용 권한을 확인한 후 연결해야 합니다.”

그 대신 data/mosquito-sample.json 파일의 샘플 데이터를 이용하여 지도와 화면을 완성한다.

# 19. 외부 날씨 데이터 연동

날씨 데이터는 OpenWeatherMap API 또는 기상청 API를 사용한다.

초기 버전에서는 JavaScript에서 사용하기 쉬운 OpenWeatherMap API를 우선 적용한다.

## 필요한 데이터

* 현재 날씨
* 현재 기온
* 최고기온
* 최저기온
* 습도
* 풍속
* 강수량
* 강수 확률
* 시간대별 예보
* 날씨 아이콘
* 데이터 관측 시간

## API 키 관리

API 키를 script.js에 직접 입력하지 않는다.

config.example.js 파일을 만든다.

예시:

const CONFIG = {
WEATHER_API_KEY: "YOUR_API_KEY",
KAKAO_MAP_API_KEY: "",
DEFAULT_LATITUDE: 37.5665,
DEFAULT_LONGITUDE: 126.9780
};

사용자가 config.example.js를 복사하여 config.js를 만든 뒤 실제 API 키를 입력하도록 README.md에 설명한다.

API 키가 없는 경우에는 샘플 날씨 데이터를 사용한다.

# 21. 모기에 대한 기본 설명

## 모기란?

모기는 파리목 모기과에 속하는 곤충이다.

일반적으로 암컷 모기는 산란에 필요한 영양분을 얻기 위해 사람이나 동물의 피를 흡혈한다.

수컷 모기는 주로 식물의 즙이나 꽃의 꿀을 먹는다.

## 모기의 성장 과정

다음 과정을 시각적으로 보여준다.

알 → 유충 → 번데기 → 성충

각 단계에 간단한 설명을 넣는다.

## 모기가 사람을 찾는 방법

* 사람이 내뿜는 이산화탄소
* 체온
* 땀 냄새
* 피부 냄새
* 움직임
* 어두운 색상

## 모기의 주요 활동 시간

* 해가 지기 전후
* 초저녁
* 새벽
* 흐리고 습한 날

단, 모기 종류에 따라 활동 시간은 다를 수 있다고 표시한다.

# 40. Claude Code에 대한 최종 작업 지시

현재 폴더에 있는 이 요구사항 파일을 먼저 전체적으로 읽는다.

이 요구사항을 바탕으로 완성도 높은 모기 환경정보 웹앱을 제작한다.

먼저 프로젝트 구조와 구현 순서를 간단히 설명한 뒤 파일을 생성한다.

HTML, CSS, JavaScript 파일을 분리하여 작성한다.

처음부터 모든 기능을 한꺼번에 구현하려 하지 말고 다음 순서대로 작업한다.

1. 기본 화면
2. 샘플 데이터
3. 지도
4. 모기지수 계산
5. 날씨 API
6. 검색과 저장 기능
7. 외부 모기 데이터 조사 및 연동
8. 오류처리
9. 반응형 및 접근성 개선

외부 데이터 연동이 확인되지 않더라도 샘플 데이터를 사용하여 전체 웹사이트가 정상 작동하도록 완성한다.

작업 중 존재하지 않는 API나 데이터 형식을 추측해서 만들지 않는다.
